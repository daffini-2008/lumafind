# LumaFind

LumaFind is an image-search app designed to help users discover visual inspiration by searching for topics and browsing image results. The current version is Part 1, which provides the responsive search interface and an empty results area ready for image results in Part 2.

I chose a warm cream, deep teal, and orange colour palette to give the app a visual identity that is different from the reference design. I also used a split hero layout with the app introduction on one side and the search panel on the other to make the interface feel more editorial and distinct. Quick-pick category chips and a Clear control were added to make common searches easier to access.
